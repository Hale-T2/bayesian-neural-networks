Bayesian Neural Networks

Neural networks with caution

Ten Jupyter notebooks that take you from Bayes' rule to Bayesian deep learning in Python. Each one follows a chapter of the text, explains the mathematics, and lets you see a network say how sure it is.

A study course by Hale Türeli, Mathematics, 2025

Start the course View the code on GitHub

The course

Work through the notebooks in order. The first six use only the scientific Python stack (NumPy, SciPy, scikit-learn); the later ones add PyTorch and TensorFlow Probability. Every notebook is saved with its outputs, so you can read it before running it.

Run the notebooks

The quickest start is the Colab link beside each notebook: it opens in your browser with nothing to install. To work locally:

git clone https://github.com/USERNAME/bayesian-neural-networks.git
cd bayesian-neural-networks
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab

Every notebook runs on a laptop CPU in under about two minutes.
